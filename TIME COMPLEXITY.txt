4. Hashing Methods & Maps (Step 1.6)
A. Direct Array Hashing (Number & Character Hashing)
Storing / Fetching: O(1) constant time per query.

Overall Array Hashing: O(N) time to construct the frequency array.

B. C++ std::map (Ordered Map / Red-Black Tree)
Fetch / Insert / Search: O(logN) in all cases (Best, Average, Worst).

Building a Map of Size N: O(NlogN).

C. C++ std::unordered_map (Unordered Map / Hash Table)
Fetch / Insert / Search:

Average Case: O(1)

Best Case: O(1)

Worst Case: O(N) (Occurs during severe hash collisions where all keys hash to the same bucket chain).
