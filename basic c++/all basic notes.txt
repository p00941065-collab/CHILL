#include<bits/stdc++.h>
using namespace std;

int main() {


int i=2;
do {
    cout<<"pd"<<i<<endl;
    i=i+1;
}
while(i<=10);
cout<<i<<endl;

return 0;


}
In C++, a do-while loop works in two steps:

Execute First: It always runs the code inside the { ... } block once, without checking any condition at all.

Check Second: Only after running that block does it evaluate the condition in while(...). If the condition is true, it repeats the loop; if false, it stops.

So for i = 11:

It ignores while(i <= 10) on the very first pass and prints pd11.

It does not ignore while(i <= 10) after that—it checks 12 <= 10, finds it false, and stops the loop from running a second time.

IMPT->DO IGNORES THE CONDITION GIVEN BY WHILE IN FIRST RUN BUT DOESNT IGNORES IN SECOND RUN ,,DO EXECUTES ITSELF FIRST THEN READS THE CONDITION GIVEN TO WHILE
