DIFFERENCE BETWEEN cout and return 

cout (Console Output): Displays data on the screen for the user to see. It does not pass any data back to the rest of your program.

return: Passes a value back to whichever part of the code called the function so it can be stored in a variable or used in further calculations. It also immediately stops the function from running.

eSum is the function name, not a variable. It represents a reusable block of code that performs an action (in this case, addition).

a and b are the parameters (or parametric variables). They act as temporary place-holders that receive the actual numbers passed in when you call the function.

int (at the very beginning) tells C++ what kind of output calculateSum produces so the rest of your program knows how to use the result.

**********************VECTORS********************


Here is what happens step-by-step in memory for both operations:

**1. After `vec.push_back({1, 2});**`

* **Outside the Vector:** C++ creates a temporary `std::pair<int, int>` object in temporary stack memory initialized with `(1, 2)`.
* **Inside the Vector:** The vector allocates memory for one `std::pair<int, int>`, and then copies (or moves) the values from the temporary pair into that allocated space.
* **Cleanup:** The temporary pair outside the vector is destroyed immediately after the statement finishes executing.
* **Final Vector State:** `vec[0]` contains the pair `{1, 2}`.

---

**2. After `vec.emplace_back(1, 2);**`

* **Outside the Vector:** No temporary object or extra memory is used. The individual arguments `1` and `2` are passed directly to the vector.
* **Inside the Vector:** The vector allocates space for a `std::pair<int, int>` and uses placement `new` to construct the pair directly inside its own memory using `1` and `2`.
* **Final Vector State:** `vec[1]` contains the pair `{1, 2}`.

---

**Memory Layout**

At the end of both lines, the vector `vec` holds a contiguous array of two pair objects in memory:

```text
vec memory layout:
+-------------------+-------------------+
|   vec[0] (pair)   |   vec[1] (pair)   |
|   first  | second |   first  | second |
|     1    |   2    |     1    |   2    |
+-------------------+-------------------+

```

The final result inside `vec` is identical, but `emplace_back` took a more direct path to get there by skipping the creation and destruction of a temporary object.

void explainStack() {
    stack<int> st;

    st.push(2);//{2,1}
